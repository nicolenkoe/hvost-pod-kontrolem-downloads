Собака уже ушла — событие сохраняется.

Исправлена потеря видеособытия при запоздалом подтверждении модели.

Скачать APK · 0.69

Устанавливается поверх предыдущей версии. Прошивка ESP32 остаётся 0.62. Фоновая запись не включена в этот выпуск.

Что изменилось

  • Распознавание связано со временем съёмки, а не временем ответа модели.
  • Ограниченный внутренний буфер удерживает больше истории; обычная предзапись остаётся пятисекундной.
  • Кадры для анализа собираются во время занятости модели. Движение без распознанной собаки не разрешает запись.
  • Для актуального кадра — «Обнаружена собака». Для сохранённого прошедшего события — «Собака была в кадре · ролик сохранён».
  • Включено ранее отправленное исправление знакомства 0.68. Главный экран не перекомпонован.

Предзапись начинается с предыдущего ключевого кадра и может быть немного длиннее пяти секунд. Проверка физического телефона пока не выполнена.
