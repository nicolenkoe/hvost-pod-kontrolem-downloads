0.53 · тестовая

Что изменилось

  • Источник обновлений перенесён на GitHub Pages.
  • Новая версия показывается в компактном окне «Обновить / Позже», с номером и типом сборки.
  • «Позже» откладывает предложение этой версии на сутки. Ручная проверка доступна в любое время.
  • Скачивание начинается после согласия. Перед установкой проверяются размер, SHA-256, версия, имя пакета и подпись.
  • В настройках есть ссылка на список версий. На сайте доступны фильтры по типу сборки.

Первый переход — вручную

Установите 0.53 один раз кнопкой скачивания. Версии до 0.53 обращаются к прежнему серверу.

Если 0.53 уже установлена и новее сборок нет, проверка должна сообщить: «Установлена актуальная версия 0.53».

Окно с 0.54 в инструкции — пример будущего предложения, а не опубликованная версия. Стабильная сборка пока не назначена. Установку подтверждает Android.
