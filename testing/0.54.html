Два отдельных файла: приложение для Android и прошивка ESP32-C3 Super Mini с SG90 на GPIO4.

Скачать APK · 0.54 ↓Прошивка + инструкция ↓

Android 11+ · ARM64. Реальная плата в среде разработки не подключена: аппаратная проверка выполняется владельцем. Новая функция выключена по умолчанию.

Что изменилось

  • Подключение ESP32-C3 Super Mini по Bluetooth BLE с индивидуальным PIN.
  • Новый раздел настроек Bluetooth · SG90: поиск платы, тест углов, цикл и Стоп.
  • Поворот при новом событии — отдельная галочка, по умолчанию выключена. Один цикл 90° → 120° → 90°, не чаще раза в 10 секунд.
  • Нет автоматического движения при подключении и повтора потерянных команд.
  • Главный экран, распознавание, голос и просмотр записей сохранены.

Как прошить ESP32-C3

  1. Отключите питание SG90. Подключите плату к компьютеру USB-кабелем с передачей данных.
  2. Откройте прошивальщик Espressif в Chrome или Edge. Выберите порт, полный образ .bin и адрес 0x0. Запишите образ, нажмите RESET.
  3. Прочитайте индивидуальный PIN в USB-мониторе 115200 командой INFO. Для повторной прошивки может потребоваться удалить старое сопряжение и прочитать новый PIN.
  4. Питание SG90 — 5 В, общий GND с ESP32, управляющий провод — GPIO4. Первый тест без нагрузки.

Полная инструкция →

SG90 — позиционная серва, не лебёдка непрерывного вращения. Поворотные углы приблизительные. Снятие PWM не отключает питание.
