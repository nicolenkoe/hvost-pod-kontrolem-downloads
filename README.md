# Хвост под контролем — сайт и загрузки

Самостоятельный публичный репозиторий приложения.

- Основной сайт: https://nicolenkoe.github.io/hvost-pod-kontrolem-downloads/
- Версии: https://nicolenkoe.github.io/hvost-pod-kontrolem-downloads/versions/
- Инструкции и проверки: https://nicolenkoe.github.io/hvost-pod-kontrolem-downloads/testing/

В репозитории только статический сайт, подписанные APK, инструкции и готовый образ ESP32. Исходники Android и прошивки, ключи подписи и пользовательские данные здесь не публикуются. Исходники подготовлены отдельно для приватного репозитория.

С 0.58 APK обращается только к этому сайту. Старые установленные версии нужно один раз вручную обновить поверх приложения без удаления. Переходной копии в Enduro не будет.

GitHub Pages публикует main через .github/workflows/pages.yml. Перед публикацией проверяются размер/SHA всех APK и согласованность update.json/release.json/versions.json. Новые APK подписываются прежним ключом из отдельного защищённого места. При каждом релизе обновляются инструкция с женской озвучкой и пронумерованный список проверок.
