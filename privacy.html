О странице и данных

Страница знакомит с тестовой Android-сборкой «Хвост под контролем» и предоставляет APK, видеоинструкции и проверки.

Сайт

Сайт размещён на GitHub Pages. На странице нет подключённых рекламных систем, аналитических счётчиков и форм сбора персональных данных. GitHub обрабатывает сетевые запросы посетителей по своим правилам.

Галочки чек-листа сохраняются в localStorage вашего браузера. Они не отправляются владельцу сайта. Кнопка «Сбросить отметки» очищает состояние текущего списка, не затрагивая данные Android-приложения.

Загрузки и инструкции

APK скачивается напрямую с GitHub Pages. Видео и аудио загружаются с этого сайта после запуска воспроизведения. Инструкции используют тестовые изображения и синтезированную озвучку.

В приложении

В 0.56 галочка «Только стабильные версии» по умолчанию выключена. При включении выбираются только совместимые сборки с отметкой «Стабильная» из каталога версий.

Начиная с 0.55 при включённой настройке «Проверять и скачивать при открытии» приложение запрашивает сведения о последней сборке на GitHub и автоматически загружает новый APK, включая тестовые и экспериментальные версии. Может использоваться мобильный интернет. Настройку можно отключить в разделе «Обновления». Установку подтверждает Android.

Для камеры требуется разрешение Android, для записи звука — микрофон. Экспериментальная интеллектуальная зона хранит на устройстве визуальные признаки и координаты рамки; исходная фотография при запоминании не сохраняется и не отправляется на сервер.

Эта страница не заменяет системные сведения Android о разрешениях приложения. Если вы отправляете обратную связь из приложения, перед отправкой проверьте выбранные вложения.
