Что означает тип?

Стабильная
Сборка, отдельно отмеченная после успешной проверки. Пока таких нет.
Тестовая
Версия для проверки новых изменений. Возможны ошибки.
Экспериментальная
Сборка с новой функцией, поведение которой ещё оценивается.

Для перехода на отдельный сайт установите 0.58 вручную поверх любой прежней версии. Старые адреса в Enduro больше не используются. Затем обновления будут проверяться на этом сайте. Android подтверждает установку; понижение версии поверх более новой обычно не поддерживается.
