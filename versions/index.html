Что означает тип?

Стабильная
Сборка, отдельно отмеченная после успешной проверки. Пока таких нет.
Тестовая
Версия для проверки новых изменений. Возможны ошибки.
Экспериментальная
Сборка с новой функцией, поведение которой ещё оценивается.

Для перехода с 0.52 на обновления через GitHub установите 0.53 вручную один раз. Затем приложение сможет предлагать новые сборки само. Android подтверждает установку; понижение версии поверх более новой обычно не поддерживается.
